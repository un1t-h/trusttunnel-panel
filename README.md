# TrustTunnel Panel

Лёгкая веб-панель для управления VPN-серверами [TrustTunnel](https://trusttunnel.org/) и их клиентами.
Сделана для Raspberry Pi и маленьких VPS: это один бинарник на Go со встроенным интерфейсом, без Docker и базы данных. Памяти занимает около 11 МБ.

Панель подключается к серверам по SSH. Она может сама установить TrustTunnel на чистый сервер, создаёт клиентов и выдаёт им QR-код или ссылку `tt://`,
а ещё показывает, кто сейчас в сети, с какой скоростью и сколько трафика потратил.

## Установка

На Raspberry Pi OS, Debian или Ubuntu (amd64, arm64, armv7):

```sh
curl -fsSL https://raw.githubusercontent.com/un1t-h/trusttunnel-panel/main/install.sh | sudo sh
```

Затем откройте `https://<ip-адрес>:8443`. Браузер предупредит о самоподписанном сертификате — это нормально.
При первом входе панель предложит создать администратора.

Повторный запуск той же команды обновляет панель, данные сохраняются. Другой порт: `curl … | sudo TTPANEL_PORT=9443 sh`.

## Как начать

1. **Добавьте сервер**: адрес VPS и пароль root. Пароль нужен один раз — панель установит свой SSH-ключ и дальше работает только по нему. Пароль не сохраняется.
2. Если TrustTunnel на сервере уже стоит, панель подхватит существующих клиентов. Если нет — нажмите **«Установить TrustTunnel»**:
   панель скачает официальный сервер, настроит сертификат (самоподписанный или Let's Encrypt), systemd и первого клиента.
3. **Добавьте клиента** — сразу откроется окно с QR-кодом для телефона, ссылкой `tt://` и файлом `.toml`.
4. На Windows ссылку удобно открывать в [TrustTunnel GUI](https://github.com/un1t-h/trusttunnel-gui).

## Возможности

- **Серверы**: статус службы, версия, пинг, нагрузка, память, аптайм, журнал, перезапуск. Установка TrustTunnel в один клик.
- **Клиенты**: создание со случайным паролем, включение и отключение, заметки, срок действия. Когда срок истекает, панель отключает клиента сама.
  Есть поиск по всем серверам.
- **Статистика в реальном времени**: кто в сети (сеансы, IP), текущая скорость скачивания и отдачи, суммарный трафик, «был в сети N минут назад».
  Данные берутся из встроенных метрик TrustTunnel (`[metrics]`, `per_client_metrics`). Метрики доступны только локально на сервере, панель читает их по SSH.
- **Удобство**: интерфейс на русском, светлая и тёмная тема, вёрстка под телефон, установка на телефон как приложение (PWA).
- **Безопасность**: HTTPS, пароль администратора в bcrypt, ограничение попыток входа, защита от CSRF, строгий CSP.
  Панель проверяет SSH-ключ каждого сервера и замечает подмену. Служба работает с ограничениями systemd.
- **Резервная копия** всех серверов и клиентов одним JSON-файлом.

## Как это устроено

- Состояние хранится в `/var/lib/ttpanel/data.json`, SSH-ключ панели — в `/var/lib/ttpanel/id_ed25519` (доступ только у root).
- При изменении клиентов панель перезаписывает `credentials.toml` на сервере (копия старой версии — в `.bak`) и перезапускает службу через 2 секунды.
  TrustTunnel перечитывает пользователей только при перезапуске, поэтому подключённые клиенты в этот момент переподключаются за пару секунд.
- Статистику панель опрашивает раз в 3 секунды, пока она открыта в браузере, и раз в 30 секунд, когда закрыта.
  TrustTunnel обнуляет счётчики при перезапуске, поэтому суммарный трафик панель накапливает сама.
  На диск данные пишутся раз в минуту, чтобы беречь SD-карту.

## Сборка из исходников

```sh
git clone https://github.com/un1t-h/trusttunnel-panel && cd trusttunnel-panel
sudo sh install.sh          # соберёт из исходников (поставит Go при необходимости) и установит службу
```

Или вручную: `go build -o ttpanel .`, затем `./ttpanel -listen :8443 -data ./data`. Флаг `-http` отключает TLS, если панель стоит за reverse proxy.
Готовые бинарники для релизов собирает GitHub Actions при публикации тега `v*`.

## Удаление

```sh
curl -fsSL https://raw.githubusercontent.com/un1t-h/trusttunnel-panel/main/install.sh | sudo TTPANEL_UNINSTALL=1 sh
```

## Файлы

| Файл | Назначение |
|---|---|
| `main.go` | запуск, HTTPS, фоновый опрос серверов, срок действия клиентов |
| `api.go` | HTTP API и задания установки |
| `tt.go` | операции с TrustTunnel по SSH: статус, клиенты, экспорт, установка |
| `stats.go` | метрики: онлайн, скорость, накопление трафика |
| `sshx.go` | SSH-ключ панели, пул соединений |
| `auth.go`, `store.go` | вход и сессии, JSON-хранилище |
| `web/` | интерфейс (HTML/CSS/JS без сборки, встраивается в бинарник) |
| `install.sh` | установка, обновление и удаление |
